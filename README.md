# DockToggle

Маленькая утилита для macOS: клик по иконке **активного** приложения в Dock сворачивает его окна
(как на Windows), повторный клик разворачивает. Работает и в обычном режиме, и в Stage Manager.

## Сборка и установка

Нужны Xcode Command Line Tools (`swiftc`).

```bash
./build.sh
```

Скрипт собирает приложение под Apple Silicon (macOS 12+), подписывает его первым найденным
сертификатом разработчика (иначе ad-hoc), ставит в `~/Applications/DockToggle.app` и создаёт `DockToggle.dmg`.

## Первый запуск

1. Запустите `~/Applications/DockToggle.app`.
2. Включите DockToggle в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».
3. Значок в строке меню позволяет выйти из приложения. Для автозапуска добавьте приложение в «Объекты входа».

Если приложение скачано из интернета и не открывается, запустите его правой кнопкой → «Открыть»
или выполните `xattr -dr com.apple.quarantine /Applications/DockToggle.app`.

## Как работает

- `CGEventTap` перехватывает клики мыши (нужен доступ «Универсальный доступ»).
- Через Accessibility API определяется, что клик пришёл на иконку приложения в Dock и что это активное приложение.
- Окна сворачиваются через `AXMinimized`. В Stage Manager свёрнутые окна не помечаются как minimized,
  поэтому утилита помнит приложения, которые свернула сама, и следующим кликом разворачивает их.
- Журнал: `~/Library/Logs/DockToggle.log`.

## Иконка

`icon/icon.png` — исходник 1024×1024, его рисует `makeicon.swift` (`swiftc makeicon.swift -o icon/makeicon && ./icon/makeicon icon/icon.png`).
